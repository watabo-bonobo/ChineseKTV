# 中国語KTV

中国語の曲名を入れると歌詞を探してきて、漢字の上にピンインを付けて表示する、スマホ向けの個人用ページです。

## できること

- **曲名で歌詞を検索**：簡体字でも、日本の漢字（例：`告白気球`、`後来`、`稲香`）でも入力できます。日本の漢字は簡体字に直してから検索します。歌手名を足すと候補を絞れます。
- **ピンイン付きで表示**：1文字ずつ上にピンインを表示します。繁体字の歌詞も簡体字に直して読みを判定するので、`還`（hái）や `著`（zhe）も正しく読みます。
- **多音字の手直し**：読みが違う字をタップすると、別の読みに切り替わります。直した読みは保存され、サビなど同じ行にもまとめて反映されます。
- **表示の調整**：文字サイズ（A− / A＋）、声調ごとの色分け、繁体字 → 簡体字の切り替え。
- **保存とオフライン**：開いた曲は自動でスマホ内に保存され、電波が弱いカラオケ店でも開けます。ホーム画面に追加するとアプリのように使えます。歌っている間は画面が消えないようにしています（対応ブラウザのみ）。
- **見つからない曲**：歌詞を貼り付けて表示することもできます。

## 歌詞の取得元

歌詞は [LRCLIB](https://lrclib.net/)（有志が登録している無料の歌詞データベース）から、スマホのブラウザが直接取得します。このサイト自体は歌詞を持っていません。周杰伦・邓丽君・刘若英・薛之谦・邓紫棋などの有名曲は見つかりますが、マイナーな曲は登録がないこともあります。その場合は「見つからない曲は歌詞を貼り付けて表示」を使ってください。

## スマホで開けるようにする（GitHub Pages）

1. GitHub でこのリポジトリを開き、**Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch でこのページのファイルがあるブランチと `/ (root)` を選び、**Save**
4. 1〜2 分待つと `https://watabo-bonobo.github.io/ChineseKTV/` で開けます
5. スマホで開き、共有メニューから **ホーム画面に追加** するとアプリのように使えます

ビルドは不要です。ファイルを置くだけで動きます。手元で確かめるときは、このフォルダで `python3 -m http.server` を実行して `http://localhost:8000/` を開きます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と処理 |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応とホーム画面用アイコン |
| `vendor/pinyin-pro.js` | ピンイン変換ライブラリ（MIT） |
| `vendor/hanzi-map.js` | 繁体字 → 簡体字、日本の漢字 → 中国の漢字の対応表（OpenCC のデータ、Apache-2.0） |
| `tools/build-hanzi-map.mjs` | `vendor/hanzi-map.js` を作り直すスクリプト |

ライセンスの詳細は `vendor/LICENSES.md` にあります。
